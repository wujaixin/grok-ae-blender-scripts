# Grok AE & Blender Scripts Repository

This repo contains useful After Effects (AE) and Blender scripts recommended by Grok for VFX workflows.

## How to use with Grok
Ask Grok to recommend or modify scripts from this repo.

## Contents
- blender/ : Python scripts for Blender
- ae/ : JSX scripts for After Effects
- configs/ : Project settings

Grok can read these files to give better recommendations!
